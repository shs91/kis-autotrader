# holidays.json에 2026-06-03(제9회 전국동시지방선거 임시공휴일) 추가

- 상태: implemented
- 우선순위: high

## 현상 분석
2026-06-03은 **제9회 전국동시지방선거 임시공휴일**로 KRX 휴장일이다(한국 지방선거는 6월 첫 수요일, 8회=2022-06-01, 9회=2026-06-03; 선거일은 관공서 공휴일 → 증시 휴장).

그러나 `holidays.json`(`_updated: 2026-01-02`, 코멘트 "매년 초 업데이트 필요")에는 2026-06-03이 **누락**되어 있다. 그 결과 실전 시스템이 휴장일에 정상 가동했다:

- `system_metrics` (kis_trader_real): 2026-06-03 `CYCLE_START` = **2,281** / `CYCLE_END` = 2,281 (쿼리 9).
- `signals`: 당일 **4,531건** 생성(쿼리 4) — 직전 영업일(06-02) 종가 기반 stale 시세로 산출된 무의미 시그널.
- 매매는 0건(휴장일이므로 정상)이나, **API 호출·연산 자원이 휴장일에 종일 소모**되었고 stale 데이터가 분석 파이프라인을 오염시켰다.

`holidays.json`의 2026 등재 목록(2026-06-06 현충일은 있으나 2026-06-03 없음):
`01-01, 01-27, 01-28, 01-29, 03-01, 05-05, 05-24, 06-06, 08-15, 09-24, 09-25, 09-26, 10-03, 10-09, 12-25`

## 제안 내용
선거일 등 정부 지정 임시공휴일이 연초 KRX 휴장일 목록에서 누락되는 패턴을 보정한다.
2026-06-03을 휴장일로 추가하고, 누락 재발 방지를 위해 코멘트에 "임시공휴일(선거일 등) 별도 확인"을 명시한다.
회귀 방지를 위해 `test_holidays.py`에 2026-06-03 휴장 단언을 1건 추가한다.
